目录内容
  五子棋围棋.html           游戏本体（单文件，五子棋+围棋、四模式、AI、音效、联机客户端）
  server.js                 联机服务端（零依赖 Node，端口 8080，管理密码 admin888）
  五子棋围棋_Windows.zip     Windows 整包（游戏+服务端+启动脚本+说明）
  五子棋围棋_Linux.tar.gz    Linux 整包（游戏+服务端+启动脚本+说明）
  五子棋围棋_Android/        安卓 APK + 安装说明

这五样是完整可交付的成品，复制到新对话后可以直接继续改。

两种棋
  五子棋：15 路，五子连珠，可选无禁手 / 标准禁手（黑三三、四四、长连）。
  围棋：9 / 13 / 19 路，中国规则数子，黑贴 3¾ 子（7.5 点），停一手两次终局，
        数子时可点棋盘标记死子。

改动要注意
  改完 五子棋围棋.html 需同步重建三端包：
    · Windows / Linux 包：把新的 html 和 server.js 换进去重新压缩；
    · APK：用 aapt2 + javac + d8 + zipalign + apksigner 流程，
      新的 html 放到 assets/index.html 再打包签名。
  html 里有 5 个拼接片段（p1~p5）的做法只在构建机上使用，交付副本里只留成品，
  直接改 五子棋围棋.html 即可（片段只影响下次整体重建）。

联机说明
  服务端只做房间、匹配和消息转发，规则判定在客户端。
  /api/join 带 game（gomoku/go）、size、rule，服务端按 game|size|rule 分桶匹配；
  /api/move 支持 pass（围棋停一手）；/api/sig 支持悔棋请求/同意/拒绝和认输。
  管理后台 /admin 可看在线人数、对局列表（含棋种和盘路）、日志，并可强制解散房间。

联机流程（双方就位门禁）
  匹配成功后，两边都要点「进入对局」，服务端 /api/ready 记录双方就位，
  两边都就位后才允许落子（服务端 /api/move 也会拒绝未就位的落子）。
  一局结束后，结果弹窗里的「继续匹配」可以直接回到匹配队列换对手，
  操作面板的「重新开局」在联机模式下同样变成「继续匹配」，不用退回首页。
